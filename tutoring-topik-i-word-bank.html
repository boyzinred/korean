Days 1–27 — Learn

Every study day is two separate runs of Exercise 2. Do not put them in one selection: mixing 50 unfamiliar words into 200 familiar ones hides how the new batch actually went.

Run 1, the new batch. Tick today's day only. Tick Korean for the question language and English for the answer. Leave “Retry a word until it is right” on. 50 words.

Run 2, the review. Tick four boxes — the days 1, 3, 7 and 16 back — and leave today's unticked. Tick English for the question language and Korean for the answer, because recall is the direction that fails first. (Tick more than one box on either side and the run mixes directions, telling you on every question which language to answer in.) Set Word limit to 60 so a ~200 word pool becomes a random 60, and put 15 in Timer in minutes.

On day 20 that is: run 1 = day 20; run 2 = days 19, 17, 13 and 4. Early on there is nothing 16 back, so tick only the boxes that exist.

Either run can be spaced instead. Set How it repeats to Spaced and the run stops counting repetitions: a word leaves it once you have answered it right three times, a miss drops it a rung and brings it round sooner, and the stars are written by what the run finds rather than by hand. The review run is where it pays — words already at three stars are asked once and drop out, so the time goes to the ones that have slipped.

Days 28–41 — Consolidate

No new words — the bank stops at day 27. This fortnight is two full passes over all 1358, then the leftovers. Use Check range for the blocks.

Days 28–32, pass one. Korean → English. One block a day: days 1–6, 7–11, 12–17, 18–22, 23–27. About 270 words each, 25 minutes on the timer.

Days 33–37, pass two. Same five blocks, but English → Korean. Harder, and the direction the writing paper needs.

Days 38–40, the leftovers. Every run ends with a Words to review box holding what you missed. Press Send to paste practice and it carries them to the Paste Your Own List page, where you drill just those until a run comes back clean.

Day 41, rehearsal. Tick All days, Word limit 100, timer 20, Korean → English. A random hundred out of the whole bank is a fair read on where you actually stand.

Two weeks is the shortest tail worth running: it is what gives the words you met on day 27 a fortnight-wide gap before the exam. Ending at day 41 leaves about two and a half weeks of slack in a two-month run.

Exercise 3 — Question Drill

Set up the exercise

The one exercise here that asks about a word rather than asking for it, and the one that shows no English once it starts. Every question is generated from the day’s own words, the sentences built on them, and a short passage written for that day — so no two runs ask the same set.

Study days
How much of each day

Two days at the same setting split the run down the middle. Pull one down and it asks less; pull it to zero and that day sits the run out without being unticked.

Kinds of question
Words to ask about

By their familiarity stars in the tables above. A question about one word — its meaning, its class, the blank it fills — only picks words at the ticked levels. Questions about a whole sentence or passage are not affected.

Check at least one study day, one kind of question, and one star level.
