Tick one box on each side for a run that always goes the same way. Tick more than one and the run mixes directions, and every question says which script to answer in.

Typed test: type each answer in the script the question asks for. Handwriting test: write each word in 한국어 with a finger or a pen, reveal the answer, and mark yourself. Speaking test: say each word in 한국어, reveal the answer, and mark yourself. Handwriting and speaking always answer in 한국어, so their questions come from the English or romanization you ticked.
