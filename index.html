How to Edit This Index Page

Open this file in a text editor and find const PAGES = [...] near the bottom. Edit the title, href, description, group, and tag values. For GitHub Pages, keep links relative, like quiz.html or folder/quiz.html. 

{
  title: "TOPIK I Vocabulary Quiz",
  href: "tutoring-topik-1-vocab.html",
  description: "Full vocabulary quiz hub with all sections.",
  group: "Quizzes",
  tag: "Vocabulary"
}

To add another page, copy one object, paste it below, and change the values. Use the same group name to place multiple cards in the same section.
